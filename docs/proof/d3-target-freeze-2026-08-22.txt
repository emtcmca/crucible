--------------------------------------------------------------------------------
A DEFECT IN THE PROTOCOL, FOUND BY RUNNING IT
--------------------------------------------------------------------------------
ADR-0017 orders step 6 (clone, --check) BEFORE step 7 (commit FROZEN.json). Run
in that order the clone has no FROZEN.json to compare against, so --check prints
"no FROZEN.json - the freeze has not been run" and can only RECOMPUTE. It did,
and returned the identical hash, so the CRLF trap the step exists for was
cleared either way.

But recomputing is the weaker assertion. Comparing needs the artifact committed
first. So FROZEN.json was committed and the clone re-run against it, and the
output above is that second run - "MATCHES the committed freeze" rather than
"RECOMPUTED (nothing to compare against)".

Recorded rather than silently reordered. A protocol whose steps cannot be run in
the order written is a protocol nobody has run.
